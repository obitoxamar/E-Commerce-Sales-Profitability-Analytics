
# E-Commerce Sales & Profitability Analytics

An interactive **Power BI dashboard** designed to analyze e-commerce sales, profitability, customer performance, product categories, and payment methods across different states and quarters.

## 📊 Project Overview

This project uses **Power BI and CSV datasets** to transform raw e-commerce data into an interactive business intelligence dashboard.

The dashboard provides a consolidated view of key business metrics and allows users to explore performance dynamically using **quarter and state filters**.

## 🛠️ Tools & Technologies

* Power BI
* DAX
* Power Query
* CSV
* Data Modeling
* Data Visualization

## 📈 Dashboard Features

* **Total Revenue** and **Total Profit** KPIs
* **Quantity Sold** and **Average Order Value (AOV)**
* State-wise revenue analysis
* Monthly profit trends
* Top customers by revenue
* Profit by product sub-category
* Payment method distribution
* Category-wise units sold
* Interactive **Quarter slicer**
* Interactive **State slicer**

## 🔍 Key Insights

The dashboard enables analysis of:

* Which states generate the highest revenue
* Monthly fluctuations in profitability
* Highest-value customers
* Most profitable product sub-categories
* Distribution of payment methods
* Category-wise sales contribution
* Performance variations across quarters and states
